# Wallpaper Changer

一个基于 Python + Qt（PySide6）的跨平台桌面壁纸管理工具。

支持 Linux 与 Windows
平台，可通过公开图片来源、本地图片库或用户自定义链接管理桌面壁纸，实现自动轮换、图库浏览、历史记录、收藏管理以及高清预览等功能。

> 本项目主要用于个人学习、技术交流和桌面美化使用。\
> 项目代码开源，第三方图片资源版权归原作者及相关权利方所有。

------------------------------------------------------------------------

## ✨ 功能特点

-   多种图片来源：在线图片接口、本地目录、自定义链接、JSON 接口
-   自动壁纸轮换：随机/顺序播放、分辨率过滤、定时切换
-   图库管理：历史记录、收藏、高清预览、图片导出
-   智能缓存：图片校验、缩略图缓存、自动清理
-   系统集成：托盘运行、开机启动、多桌面环境适配
-   稳定运行：后台任务、异常处理、日志记录

# 🚀 快速运行

## 环境要求

-   Python 3.9+
-   PySide6
-   requests
-   Pillow

安装依赖：

``` bash
python -m pip install -r requirements.txt
```

启动：

``` bash
python main.py
```

后台托盘启动：

``` bash
python main.py --minimized
```

环境检测：

``` bash
python main.py --doctor
```

# 📦 编译与打包说明

## Linux Debian / Ubuntu

### 构建 deb 安装包

``` bash
bash packaging/linux/build-deb.sh 1.0.0
```

生成：

    dist/wallpaper-changer_1.0.0_all.deb

安装：

``` bash
sudo apt install ./dist/wallpaper-changer_1.0.0_all.deb
```

### 构建自包含版本

如果希望不依赖系统 Python 和 Qt：

``` bash
bash packaging/linux/build-deb.sh 1.0.0 --bundle
```

------------------------------------------------------------------------

## AppImage 打包

生成 AppImage：

``` bash
bash packaging/linux/build-appimage.sh 1.0.0
```

运行：

``` bash
chmod +x dist/Wallpaper-Changer-1.0.0-x86_64.AppImage
./dist/Wallpaper-Changer-1.0.0-x86_64.AppImage
```

------------------------------------------------------------------------

## Windows 编译

安装依赖：

``` bat
pip install -r requirements.txt
pip install pyinstaller
```

### 普通目录版

``` bat
packaging\windows\build.bat
```

### 单文件 EXE

``` bat
packaging\windows\build.bat 1.0.0 one
```

PowerShell：

``` powershell
.\packaging\windows\build.ps1
```

生成：

    dist/
     ├── Wallpaper Changer/
     │   └── Wallpaper Changer.exe
     └── WallpaperChanger-版本号-Setup.exe

推荐使用目录版，启动速度更快，也更少触发安全软件误报。
